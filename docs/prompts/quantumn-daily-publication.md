# Quantumn 出版编辑入口

本文件为兼容旧任务路径保留的入口。当前完整生产协议在 [quantumn-editorial-v2.md](quantumn-editorial-v2.md)。作者和审稿任务必须完整读取该协议，以及当前 `publication_operator.py --help` 和 `publication_editorial_remote.py --help`。

旧的每期 1200–2000 字符短专栏目标已废止。既有已发布短文保留原版，并明确标记“历史短文”；不能把历史正文重新标签化为完整书。

- 完整书：至少 20,000 有效正文汉字、至少八个实质章节。
- 连载章节：至少 3,000 有效正文汉字，显示章次与学习目标。
- 字数只是准入下限；事实校对、原理解释、完整例子、反例边界、读者疑问、跨章连贯性与去重仍必须独立审核。
- 发现缺口即定向补研，保存同一 issue 的拒稿、gap、revision 与验收条件；不能靠换日期、重复首期或旧批准逃过返工。
- Hermes 唯一 AI Runtime；PublicationStore 只保存出版业务状态和原生会话的输入/输出绑定回执，不保存另一套 AI 会话。
- 作者只备稿和进入私有待审区；独立审稿不改正文、不 stage。待原生审稿会话真正结束后，由可信确定性操作器回读、签名、验证和 stage，再交原有发行任务 release。
- 第三方来源仍尊重原作和授权；元数据入口不是第三方全文，不能因本协议要求长书就扩写他人原作或绕过权利门禁。

实际运行是否已采用新协议，必须核对 live Cron、活动脚本 hash、服务器发布版本及真实回执；仓库文档本身不是部署证据。
